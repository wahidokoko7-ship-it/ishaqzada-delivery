# اسحاق‌زاده آنلاین ډیلیوري

دا د PWA په بڼه د ډیلیوري مدیریت اپلیکیشن نمونه ده.

## مهم
دا نسخه د Demo/Prototype لپاره ده او معلومات په `localStorage` کې ساتي. د څو موبایلونو ترمنځ د ریښتیني آنلاین همغږۍ لپاره Firebase/Supabase یا بل Backend باید ورسره وصل شي.
